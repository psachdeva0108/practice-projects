A collection of **React.js practice projects** built to strengthen frontend development skills and explore modern React concepts through hands-on implementation.

## Projects

* **Food Delivery** — Context API, useReducer, custom hooks, REST APIs
* **Redux & Advanced Redux** — Redux state management and advanced patterns
* **Shopping Cart** — Cart state and component-based UI
* **Forms** — Form handling and validation
* **Place Picker** — Browser APIs and interactive UI
* **MCQ Quiz** — State management and timed interactions
* **Tic Tac Toe** — React state and component logic
* **Investment Calculator** — Controlled inputs and calculations
* **Manage Tasks** — State-driven task management
* **Multi Page** — React routing and navigation
* **Stop Timer** — useEffect and timer management
* **Share Opinions** — Forms and user interactions
* **Gucci Clone** — UI replication and styling

## Tech Stack

**React.js · JavaScript · CSS · React Router · Redux · Context API · REST APIs**

## Purpose

This repository tracks my hands-on practice with **React.js**, covering component architecture, state management, routing, forms, API integration, custom hooks, and modern React patterns.
